# 4.0 线性回归模型（Linear Regression Model）

## 💡 核心理解

是的，**线性回归可以看作机器学习中最基础、最经典的监督学习模型之一**。

它非常适合用来学习机器学习的基本思想，因为虽然它本身很简单，但已经包含了机器学习最核心的一整套逻辑：

> [!important]
> **数据 → 模型 → 预测 → 计算误差 → 调整参数 → 得到更好的模型**

后面学习 Logistic Regression、Neural Network 甚至 Deep Learning 时，这个基本框架都不会发生本质变化，只是模型会越来越复杂。

---

## 1. 线性回归在机器学习中的位置

```text
Machine Learning
│
├── Supervised Learning
│   │
│   ├── Regression
│   │   └── Linear Regression  ← 当前学习
│   │
│   └── Classification
│
└── Unsupervised Learning
```
因此几个概念的层级关系是：

- **Machine Learning**：整个领域
- **Supervised Learning**：一种机器学习方式
- **Regression**：监督学习中的一种任务
- **Linear Regression**：解决 Regression 问题的一种具体模型

也就是说：

> [!note]  
> **Regression 是任务类型，Linear Regression 是完成这种任务的一种模型。**

---

# 2. 什么是 Supervised Learning？

监督学习的数据中同时存在：

(x,y)

其中：

- $x$：输入（Input / Feature）
- $y$：正确答案（Target / Label）

例如房价预测：

x=房屋面积x=\text{房屋面积} y=真实房价y=\text{真实房价}

训练数据可能是：

|房屋面积 $x$|房价 $y$|
|---|---|
|2104|400|
|1416|232|
|1534|315|
|852|178|

机器可以看到：

```
2104 → 400
1416 → 232
1534 → 315
```

因为训练过程中存在正确答案，所以叫：

**Supervised Learning（监督学习）**

---

# 3. 什么是 Regression？

Regression（回归）的目标是：

> **预测一个连续数值。**

例如：

- 房价：$220,000
- 温度：23.7°C
- 股票价格：152.31
- 肿瘤大小：2.8 cm

这些答案理论上可以有大量甚至无限多个可能值。

因此：

> [!important]  
> **Regression = 预测连续数值的任务。**

与之对应的是 Classification：

```
Regression
→ 预测数字
→ 房价 = 220000

Classification
→ 预测类别
→ 是否患病 = Yes / No
```

---

# 4. Linear Regression 做了什么？

现在我们的任务是：

x=房屋面积

预测：

y=房价

Linear Regression 提出了一个非常简单的假设：

> **$x$ 和 $y$ 之间的关系，可以近似用一条直线表示。**

因此定义：

$$
f_{w,b}(x)=wx+b
$$

也经常简写为：

$$
f(x)=wx+b
$$

模型接收输入：

$x$

经过函数：

$f(x)$

得到预测结果：

$^\hat y$
因此：

```
x
│
│ feature
↓
f(x) = wx + b
│
│ model
↓
ŷ
prediction
```

---

# 5. $y$ 和 $\hat y$ 的区别

这是机器学习中一个非常重要的区别。

## $y$

表示：

**真实答案（Target / Ground Truth）**

例如：

y=400

意味着真实房价为：

$400,000

---

## $\hat y$

读作：

**y-hat**

表示：

**模型预测的结果（Prediction）**

例如：

$\hat y$=390

意味着模型预测：

$390,000

因此：

y≠$\hat y$

完全正常。

例如：

```
真实数据：

x = 2104
y = 400


模型：

x = 2104
    ↓
  f(x)
    ↓
ŷ = 390
```

接下来机器学习要解决的问题就是：

> **怎样让 $\hat y$ 尽可能接近 $y$？**

---

# 6. $w$ 和 $b$ 是什么？

在线性回归：

$f(x)=wx+bf(x)=wx+b$

中：

## $w$：Weight / Slope

控制直线的斜率。

也就是说：

> **$x$ 改变时，预测结果变化得有多快。**

例如：

```
w 大
→ 直线更陡

w 小
→ 直线更平
```

---

## $b$：Bias / Intercept

控制直线整体在纵轴上的位置。

当：

$x=0$

时：

f(0)=b

因此：

```
b 增大
→ 整条线向上移动

b 减小
→ 整条线向下移动
```

可以简单理解为：

> [!note]  
> $w$ 控制「倾斜程度」，$b$ 控制「上下位置」。

---

# 7. 模型真正“学习”的是什么？

这是这一节最重要的思想。

我们已经提前规定了模型形式：

$f(x)=wx+bf(x)=wx+b$

所以机器并不是自己发明：

$wx+b$

这个公式。

机器真正需要学习的是：

$\boxed{w,b}$

也就是说：

> **从训练数据中找到最合适的 $w$ 和 $b$。**

例如可能存在：

$f(x)=0.1x+20$

也可能：

$f(x)=0.15x+30$

或者：

$f(x)=0.2x−10$

这些都是 Linear Regression Model。

区别只在于：

$w,b$

不同。

所以：

> [!important]  
> **机器学习中的 Learning，在这里就是学习参数 $w$ 和 $b$。**

---

# 8. Training Set、Learning Algorithm 和 Model 的关系

完整流程是：

```
Training Set
(x, y)
    ↓

Learning Algorithm
利用训练数据寻找参数

    ↓

得到参数
w, b

    ↓

得到 Model
f(x) = wx + b

    ↓

输入新的 x

    ↓

Prediction
ŷ
```

因此可以写成：

$\boxed{ Training\ Data \rightarrow Learning \rightarrow Model \rightarrow Prediction }$

# 9. 为什么叫 Linear Regression？

这个名字可以拆成两部分。

## Linear

因为模型：

$f(x)=wx+b$

在二维坐标系中是一条直线。

所以叫：

**Linear（线性）**

---

## Regression

因为模型预测的是连续数值，例如：

220.3220.3 350.8350.8 472.1472.1

所以叫：

**Regression（回归）**

因此：

> **Linear Regression = 使用线性函数完成回归任务。**

---

# 10. 什么是 Univariate Linear Regression？

当前课程中的模型只有一个 Feature：

$x=\text{size}$

所以：

$f(x)=wx+b$

这叫：

**Linear Regression with One Variable**

或者：

**Univariate Linear Regression**

其中：

```
uni = one
variate = variable
```

所以：

> **Univariate = 一个变量**

以后可能有：

$x_1=\text{面积}  x_2=\text{卧室数量}  x_3=\text{房龄}$
这时候模型就会拥有多个 Feature。

# 11. 一个非常重要的机器学习框架

线性回归虽然简单，但是它已经包含了机器学习最核心的结构：

```
Input
x
↓

Model
f(x)
↓

Prediction
ŷ
↓

与真实答案 y 比较
↓

Error / Loss
↓

修改 Model Parameters
↓

得到更好的预测
```

因此学习 Linear Regression 的真正意义，并不仅仅是学会：

$y=wx+b$

而是在学习：

> **机器学习到底是怎么“学习”的。**

---

# 12. 为什么 Linear Regression 是最基础的机器学习模型之一？

因为它同时包含了机器学习的几个核心元素：

### ① Data

$(x,y)$

---

### ② Model

$f_{w,b}(x)=wx+b$

---

### ③ Parameters

$w,b$

---

### ④ Prediction

$^\hat y$

---

### ⑤ Error

比较：

$^\hat y$

和：

$y$

---

### ⑥ Optimization

不断调整：

$w,b$

让模型预测得越来越准确。

所以虽然 Linear Regression 很简单，但机器学习的基本骨架已经完整出现了。

---

# 13. 从 Linear Regression 到 Neural Network

以后学习神经网络时，会发现核心结构其实没有变化。

Linear Regression：
$x→fw,b​(x)→y^​$

Neural Network：
$x→fθ​(x)→y^​$

最大的区别只是：

Linear Regression 的参数可能只有：

w,b

而 Neural Network 的参数可能有：

θ1,θ2,θ3,…

甚至数十亿个。

但是核心逻辑仍然是：

```
数据
↓
模型
↓
预测
↓
计算误差
↓
调整参数
```

> [!important]  
> **Linear Regression 是理解现代机器学习和深度学习训练逻辑的最小模型。**

---

# 14. 本节留下的问题

现在我们知道：

f(x)=wx+b

但是还存在一个问题：

> **到底什么样的 $w,b$ 才算“好”？**

例如：

w=0.1, b=20w=0.1,\ b=20

和：

w=0.15, b=30w=0.15,\ b=30

哪一个更好？

机器需要一个客观标准来衡量：

> **当前模型到底错得有多严重？**

这就引出下一节：
$\boxed{\text{Cost Function}}$

Cost Function 解决：

> **“这一组 $w,b$ 好不好？”**

之后还有：

$\boxed{\text{Gradient Descent}}$

Gradient Descent 解决：

> **“如果不好，该怎样修改 $w,b$？”**

因此后面的知识链可以理解为：

```
Linear Regression
f(x)=wx+b
↓
w,b 应该是多少？
↓
Cost Function
衡量模型有多差
↓
Gradient Descent
调整 w,b
↓
找到较好的模型参数
```

# 📌 本节总结

> **线性回归是最基础、最经典的监督学习模型之一。**
> 
> 在监督学习中，我们拥有由 $(x,y)$ 组成的训练数据，其中 $x$ 是 Feature，$y$ 是 Target。
> 
> 在线性回归中，我们假设 $x$ 和 $y$ 之间可以近似用：
> 
> fw,b(x)=wx+bf_{w,b}(x)=wx+b
> 
> 表示。
> 
> 输入 $x$ 后，模型产生预测：
> 
> y^=fw,b(x)\hat y=f_{w,b}(x)
> 
> 机器学习真正需要学习的不是公式 $wx+b$ 本身，而是其中最合适的参数：
> 
> w,bw,b
> 
> 因此可以把线性回归的训练理解为：
> 
> **利用训练数据寻找合适的 $w,b$，使预测值 $\hat y$ 尽可能接近真实值 $y$。**
> 
> 这已经包含了整个机器学习最基本的思想：
> 
> **Data → Model → Prediction → Error → Optimization**
