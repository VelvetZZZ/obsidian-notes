# C语言基础：数组 (Array)

> [!abstract] 什么是数组？
> 数组是一种**容器**（放东西的东西），特点是：
> - 其中所有的元素具有**相同的数据类型**。
> - **一旦创建，不能改变大小**。
> - 💡 *底层原理：数组中的元素在内存中是连续、依次排列的。*

---

## 1. 定义数组

**语法格式**：
`<类型> 变量名称[元素数量];`

**示例**：
```c
int grades[100];
double weight[20];
```

> [!info] 关于元素数量的规定
> 
> - 元素数量必须是**整数**。
>     
> - 在 C99 标准之前：元素的数量必须是**编译时刻确定的字面量**（即不能用变量来定义数组大小）。
>     

## 2. 数组的单元与下标

定义了 `int a[10]` 意味着我们有了一个包含10个单元的数组：`a[0], a[1], ..., a[9]`。
![[Pasted image 20260529204326.png]]
- **单元即变量**：数组的每个单元就是数组类型的一个变量。
    
- **下标（索引）**：使用数组时放在 `[]` 中的数字叫做下标或索引。
    
    - ⚠️ **核心常识：下标从 0 开始计数！**
    
- **左值属性**：数组单元可以出现在赋值的左边或右边（在赋值左边的叫做“左值”）。
    
    - 例如：`a[2] = a[1] + 6;`
![[Pasted image 20260529204400.png]]
## 3. ⚠️ 安全隐患：越界访问

> [!danger] 致命的 Segmentation Fault 编译器和运行环境**都不会检查**数组下标是否越界（无论是读还是写）。
> 
> - 一旦程序运行，越界的数组访问可能导致**程序崩溃 (Segmentation Fault)**。
>     
> - 也可能运气好，没造成严重后果（但这是极其危险的定时炸弹）。
>     
> - 🛡️ **程序员的绝对责任**：必须在代码逻辑中保证只使用有效的下标值：`[0, 数组的大小 - 1]`。
>     ![[Pasted image 20260529204419.png]]

## 4. 经典实战：计算平均数

我们需要记录下用户输入的所有数字，计算平均值，然后找出大于平均值的数。

### 第一版代码（存在隐患）：


```c
#include <stdio.h>

int main() {
    int x;
    double sum = 0;
    int cnt = 0;
    
    int number[100]; // 1. 静态定义数组，大小为100
    
    scanf("%d", &x);
    while ( x != -1 ) {
        number[cnt] = x; // 2. 赋值
        sum += x;
        cnt ++;
        scanf("%d", &x);
    }
    
    if ( cnt > 0 ) {
        printf("%f\n", sum/cnt);
        int i;
        for ( i=0; i<cnt; i++ ){ 
            if ( number[i] > sum/cnt ) { 
                printf("%d\n", number[i]); 
            }
        }
    }
    return 0;
}
```

> [!warning] ⚠️ 上述程序的安全隐患 **这个程序是危险的，因为输入的数据可能超过 100 个！** 一旦用户输入的数字达到 101 个，`cnt` 就会变成 100，程序就会执行 `number[100] = x;`。这超出了合法下标 `[0, 99]` 的范围，直接导致**数组越界**！

## 5. 终极解决方案：C99 变长数组 (VLA)

为了解决数组大小不够用的问题，我们可以改变策略：**先让用户输入一共有多少个数字要计算**，然后再根据这个数量来创建数组。

> [!success] 核心技巧 (C99 ONLY!) 在 C99 标准中，允许使用**变量**（而不是固定的数字）来定义数组的大小！

**安全版改进代码**：

```c
int x;
double sum = 0;
int cnt; // 用来接收用户打算输入多少个数字

printf("请输入数字的数量：");
scanf("%d", &cnt);

if ( cnt > 0 ) {
	// 🌟 核心突破：数组的大小由变量 cnt 决定！
    int number[cnt]; 
    
    scanf("%d", &x);
    while ( x != -1 ) {
        number[cnt] = x; // (注：这里若搭配 for 循环按 cnt 次数读取会更严谨)
        sum += x;
        cnt ++;
        scanf("%d", &x);
    }
}
```

## 6. 补充拓展：长度为 0 的数组？

> [!question] 存在 `int a[0];` 这样的数组吗？
> 
> - **可以存在**（编译器通常不会报错）。
>     
> - **但是无用**。
>     
> - **原因**：长度为 0 意味着这个数组没有任何有效的下标空间，你既不能往里面存东西，也不能从中读东西。
