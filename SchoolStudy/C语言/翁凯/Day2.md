# 2.1.5 常量vs变量
1. 会变的是变量；不会变的是常量；直接写在程序里的是直接量；

2. 更好的方式：定义常量

	- 为了写出更好的代码，推荐的方式是明确地定义一个常量，而不是随处使用“直接量”。
    
	- 在C语言中，可以使用 `const` 关键字来定义常量，语法示例为：
```c
	const int AMOUNT = 100;
```
    
	- 这种定义常量的方法属于 C99 标准。
    
	- 翁恺老师在视频中强调，给常量起一个有意义的名字（如用 `AMOUNT` 代替 `100`），可以让别人更容易理解这个数字在程序中的具体含义。
3. `const`
	- `const`是一个修饰符，加在int前面，用来给这个变量加上一个const（不变的）属性。表示这个变量的值一旦初始化，就不能再修改了。
```c
	  int change = AMOUNT - price;
```
	- 试图把常量进行修改，放在赋值运算符的左边，会报错！
4. 让用户输入变量`AMOUNT`的值，而不是使用固定的初始值
```c
#include <stdio.h>

int main(){
	int amount = 100;
	int price = 0;
	
	printf("请输入金额（元）：");
	scanf("%d",&price);
	
	printf("请输入票面");
	scanf("%d",&amount);
	
	int change = amount - price;
	
	printf("找您%d元。\n", change);

}

```
**“传值”** 与 **“传址（传地址）”** 的区别:
- **`printf` 是“读”数据**：只需要给它**变量的值**（把里面的东西拿给它看）。
- **`scanf` 是“写”数据**：必须给它**变量的地址 `&`**（告诉它新数据该存到哪个具体位置）。

# 2.1.6 浮点数
### `float` 与 `double`

C语言里主要有两种类型的浮点数，你可以把它们理解为“小号容器”和“大号容器”：

- **`float`（单精度浮点数）**：占用空间小，但能表示的小数位数有限，精确度相对较低。
    
- **`double`（双精度浮点数）**：占用空间大一倍，精确度更高。**在现代编程中，我们几乎默认都使用 `double`**，因为现在的电脑不在乎多占那点内存，而计算的准确性更重要。


### 2. 核心对比速查表

这是你以后写代码时最常需要回顾的表格，特别注意它们在 `scanf` 中的区别！

|**数据类型**|**内存大小（通常）**|**有效数字精度**|**printf 输出时用**|**scanf 输入时用**|
|---|---|---|---|---|
|**float**|4 字节|约 7 位|`%f`|**`%f`**|
|**double**|8 字节|约 15 位|`%f`|**`%lf`** (小写的L)|

_(注：在较新的C语言标准中，`printf` 打印 `double` 用 `%f` 即可，但 `scanf` 读取 `double` **必须**用 `%lf`，绝对不能混用！)_

### 3. 浮点数的两种写法（直接量）

当你在代码里直接写一个小数时，C语言默认它是 `double` 类型的。

1. **普通小数写法**：
    
    - `3.14`
        
    - `-0.5` （也可以简写为 `-.5`）
        
    - `5.0` （即使是整数，加了 `.0` 电脑也会把它当浮点数处理）
        
2. **科学计数法**（用于特别大或特别小的数）：
    
    - `1.23e4` （代表 1.23 乘以 10的4次方，即 12300）
        
    - `5.6e-3` （代表 5.6 乘以 10的负3次方，即 0.0056）

### 4. 新手必踩的三大“深坑” ⚠️

这三个坑是自学C语言时最容易让人抓狂的地方，提前了解可以帮你省下大量Debug的时间：

### 第一坑：整数除法的“截断”效应

这是初学者最容易犯的错误。

如果你写 `10 / 3`，C语言会发现两边都是整数，于是它会执行**整数除法**，结果是 `3`，小数部分被直接丢弃了。

**怎么破解？** 只要除号两边**至少有一个是浮点数**，电脑就会执行浮点数除法。

- `10.0 / 3` 👉 结果是 `3.333333`
    
- `10 / 3.0` 👉 结果是 `3.333333`
    

### 第二坑：`scanf` 的 `%lf`

前面我们刚讨论过 `scanf` 需要地址（`&`）。因为 `double` 占用的内存比 `float` 大，如果你用 `%f` 去让 `scanf` 读取一个 `double` 变量，电脑写入内存的尺寸就不对，会导致读入全是乱码或 0。

**记住：只要定义了 `double`，输入就老老实实写 `scanf("%lf", &变量名);`**

### 第三坑：永远不要用 `==` 直接判断两个浮点数是否相等

电脑内部是用二进制来存储小数的，很多小数（比如 `0.1`）在二进制里是无限循环的，所以电脑存的其实是一个“非常非常接近的近似值”。

如果你写 `if (a == 0.1)`，大概率会判断失败。目前你只需要知道：**浮点数是不绝对精确的**。等以后学到更深处，会学到如何用“差值小于某个极小值”来判断它们是否相等。
