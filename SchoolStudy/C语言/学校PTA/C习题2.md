1. 调用数学库函数时，编译预处理命令为 `include math.h`。<font color="#ff0000">F</font>
	- 在 C 语言中，所有的预处理指令必须以 **`#`** 开头（如 `#include`, `#define`）。
	- 标准的写法应该是 `#include <math.h>` 或 `#include "math.h"`。

2. 调用输入输出库函数时，编译预处理命令为`#include <stdio.h>`。<font color="#ff0000">T</font>

	- `stdio` 代表 **st**andard **i**nput **o**utput。
	- 这里的语法完全正确：有 `#` 号，有正确的库名，有尖括号。
	
3. 假设`k`是整型变量，计算表达式`1.0/k` 后结果的数据类型是浮点型。<font color="#ff0000">T</font>
	- **类型提升（Type Promotion）：** 在 C 语言的算术运算中，如果两个操作数类型不同，系统会自动<span style="background:rgba(236, 57, 57, 0.55)">将“低级”类型转换为“高级”类型。</span>
	- 这里 `1.0` 是 `double`（浮点型），`k` 是 `int`（整型）。
	- 计算时：`double / int` $\rightarrow$ `double / double` $\rightarrow$ 结果为 `double`
4. 假设 `k` 是整型变量，计算表达式 `1/k` 后结果的数据类型是整型。<font color="#ff0000">T</font>
	- **整数除法：** 如果两个操作数都是 `int`，那么结果也一定是 `int`。
	- 即便结果有小数位（比如 `1/2`），C 语言也会直接**截断**小数部分，返回 `0`。
