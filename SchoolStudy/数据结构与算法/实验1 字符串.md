## 概念笔记
### 1. 两个概念
1. <span style="background:rgba(236, 57, 57, 0.55)">空串</span>：<span style="background:rgba(236, 57, 57, 0.55)">""</span> 里面一个字符都没有，$length = 0$
2. <span style="background:rgba(236, 57, 57, 0.55)">空格串</span>：<span style="background:rgba(236, 57, 57, 0.55)">" "</span> 里面实际上有一个字符：空格，$length = 1$
### 2. 什么叫“子串”？
子串（Substring）：一个字符串中<span style="background:#fdbfff">连续的</span>一段字符序列

子串最重要的是：

> **必须连续，而且顺序不能变。**

例如：

```
S = "abcdef"
```

这些是子串：

```
"abc"
"bcd"
"cde"
"abcdef"
""
```

但这个不是：

```
"ace"
```

# PTA题目

## 判断题

### 1-1 假设模式串是`abababaab`，则<font color="#ff0000">KMP</font><span style="background:rgba(236, 57, 57, 0.55)">模式匹配</span>算法中的<span style="background:#b1ffff">next[j] </span>= `0 1 1 2 3 4 5 6 2`。<font color="#ff0000">T </font>

#### 1.<span style="background:rgba(236, 57, 57, 0.55)">字符串匹配/模式匹配</span>：假设我有一个大字符串：

```
S = "xxabababaabyy"
```

现在我要找：

```
P = "abababaab"
```
也就是问：
> `"abababaab"` 有没有出现在 `"xxabababaabyy"` 里面？这件事就叫模式匹配

其中`S`叫主串;`P`叫模式串

2.<span style="background:rgba(160, 204, 246, 0.55)">KMP的想法</span>
>**KMP = 匹配失败以后，不全部重来，而是利用已经匹配过的重复部分继续。**

3.`next[j]` 你先把它理解成：
> **如果第 j 个位置匹配失败了，模式串下一次应该回到哪个位置继续比较？**
##### KMP：next 数组速记

###### 1. next 数组是干什么的？

KMP 用于字符串模式匹配。
当模式串在第 `j` 个字符匹配失败时：
> `next[j]` 表示模式串下一次应该跳到哪个位置继续比较。

所以可以简单记：
> **next = 失配后往哪里跳**

---
###### 2. 本课程 next 数组的计算公式

设模式串为：

$$
P = p_1p_2\cdots p_m
$$

特殊情况：

$$
next[1] = 0
$$

对于：

$$
j > 1
$$

先看第 `j` 个字符前面的部分：

$$
P[1\ldots j-1]
$$

找到它的：

> <span style="background:rgba(240, 167, 216, 0.55)">**最长相同真前缀和真后缀**</span>

如果这个最长相同部分的<font color="#ff0000">长度为 L</font>，那么：

$$
\boxed{next[j] = L + 1}
$$

---
###### 3. 什么是“最长相同前后缀”？

例如：

```text
abab
```
尝试相同长度的前缀和后缀：
```
长度 1：
前缀 a
后缀 b
❌

长度 2：
前缀 ab
后缀 ab
✅

长度 3：
前缀 aba
后缀 bab
❌
```

因此最长相同前后缀为：

```
ab
```

长度：$L=2L=2$

所以：
$next=L+1=3next = L+1 = 3$
---

###### 4. 做题固定步骤

如果要求：
```
next[j]
```
###### Step 1：遮住第 j 个字符

只看：
$P[1\ldots j-1]$

---
###### Step 2：找“最长相同前缀和后缀”
要求：
> <span style="background:rgba(236, 57, 57, 0.55)">前缀和后缀长度必须相同</span>。

依次尝试：
```
前 1 个 vs 后 1 个
前 2 个 vs 后 2 个
前 3 个 vs 后 3 个
...
```
找最大的相同长度 `L`。

---
###### Step 3：套公式
$\boxed{next[j]=L+1}$
特殊记：
$\boxed{next[1]=0}$

##### 例题
模式串：

```
abababaab
```

标号：

```
位置：1 2 3 4 5 6 7 8 9
字符：a b a b a b a a b
```

###### next[5]

遮住第 5 位，只看：

```
abab
```

最长相同前后缀：

```
ab
```
长度：
$L=2$
所以：
$next[5]=2+1=3$
###### next[8]

遮住第 8 位，只看：
```
abababa
```
最长相同前后缀：
```
ababa
```
长度：
$L=5$
所以：
$next[8]=5+1=6$
##### next[9]

遮住第 9 位，只看：

```
abababaa
```

尝试：

```
长度 1：
a == a
✅

长度 2：
ab != aa
❌
```

所以最长相同前后缀只有：

```
a
```

长度：
$L=1$
因此：
$next[9]=1+1=2$

---

###### 最终结果

```
模式串： a b a b a b a a b
位置：   1 2 3 4 5 6 7 8 9
next：   0 1 1 2 3 4 5 6 2
```

所以题目：

```
abababaab 的 next[j] =
0 1 1 2 3 4 5 6 2
```

答案：

**T**

### 考试速记

看到求 `next[j]`：

> **遮住 j，看前面；找最长相同前后缀；长度 + 1。**

即：
$\boxed{ next[j] = \text{最长相同真前后缀长度}+1 }$

并单独记住：

$\boxed{next[1]=0}$

---
### 易错点

1. 前缀和后缀比较时，长度必须一样。
2. <font color="#ff0000">不能把整个字符串自己算作前后缀</font>。
    - 要找的是“真前缀”和“真后缀”。
3. 算 `next[j]` 时，不看第 `j` 个字符。
    - 只看 `1 ~ j-1`。
4. 不同教材的 `next` 定义可能不同。
    - 有的从 0 开始编号。
    - 有的会出现 `-1`。
    - 本课程按：
    ```
 next[1] = 0
    ```
    
    的定义来做题。
